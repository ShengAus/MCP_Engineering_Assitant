# Design Limitations

## not-certified-design-software

This MCP sample is not certified electrical design software. It must not be used for real electrical design decisions without review by a qualified engineer.

## simplified-engineering-scope

The calculation tool intentionally uses a narrow simplified formula. It does not model cable temperature, installation conditions, harmonics, unbalanced loads, protection settings, fault current, equipment constraints, or jurisdiction-specific standards.

## ai-output-safety

The LLM or host should not invent standards, catalogue values, or compliance conclusions. Calculations should come from deterministic tools, and final reports should include assumptions, evidence, and limitations.

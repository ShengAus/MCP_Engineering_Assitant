# Cable Selection Checklist

## required-inputs-before-sizing

Before selecting a cable size, an engineering workflow should collect at least:

- system voltage and phase configuration
- design current or load profile
- route length
- conductor material
- installation method
- ambient temperature assumptions
- grouping or derating conditions
- acceptable voltage drop limit
- protection and fault requirements

The demo only calculates voltage drop from a small subset of these inputs.

## review-steps

A complete cable selection workflow should review current capacity, voltage drop, short-circuit withstand, protection coordination, installation constraints, and relevant standards.

This sample does not perform those checks.

# Limitations

This project is a demonstration of MCP tool orchestration for engineering-style workflows.

It is not certified electrical design software and must not be used for real design decisions without qualified engineering review.

Known limitations:

- Simplified voltage drop formula only
- No standards compliance checking
- No cable derating
- No installation method assessment
- No thermal model
- No protection coordination
- No short-circuit or fault analysis
- Mock documentation only
- Deterministic local retrieval rather than production search
- AI/agent outputs should be treated as advisory

The goal is to demonstrate maintainable architecture, typed tool boundaries, deterministic calculation tools, and traceable reporting.
